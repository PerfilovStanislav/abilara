# Abilara
Ability-based authorization for Laravel with nested inheritance, recursive permissions, and unified access control

[![Packagist](https://img.shields.io/packagist/v/perfilov/abilara.svg)](https://packagist.org/packages/perfilov/abilara)
[![PHP](https://img.shields.io/packagist/php-v/perfilov/abilara.svg)](https://www.php.net/)
[![License](https://img.shields.io/github/license/PerfilovStanislav/abilara.svg)](https://github.com/PerfilovStanislav/abilara/blob/main/LICENSE)

---

## Install
```bash
composer require perfilov/abilara

php artisan abilara:install

php artisan migrate

composer remove perfilov/abilara
```
